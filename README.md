# Construction Data for Binary LCD Codes of Codimension 8

This repository contains the construction data for the paper:

> K. Ishizuka and Y. Kamio, "Binary caps and LCD codes with large dimensions," 2026.

## Data Files

### `codim8_data.sobj`

SageMath object file containing explicit LCD code constructions for codimension 8.

## Verification Script

- `codim8_verify.sage` — Verifies all entries in `codim8_data.sobj`

### Running

```bash
sage codim8_verify.sage
```
